# 댓글 답글

읽는 사람은 스크롤 중이다. **짧고, 먼저 공감하고, 질문으로 끝낸다.** 그게 전부다.
설명하고 싶어지면 그건 다음 카드뉴스 소재이지 답글이 아니다.

## 기본형

```
[공감 — 상대 말이 맞다고 인정] + [새 사실 한 개] + [짧은 질문]
```

- **1~2문장 + 질문. 영어 150자 안팎, 200자를 넘기지 않는다.** 문단 나누지 않는다.
  길게 쓰고 싶어질 때 버릴 것부터 정한다: 수식어 → 부연 → 두 번째 사실 순.
- **보통은 물음표로 끝낸다** — 마침표로 끝내면 대화가 닫히고, 질문은 상대가 자기 나라
  얘기를 하게 만든다. **단, 상대가 우리를 정정했거나 자기 목격담을 말한 경우는 예외다.**
  거기서 되물으면 "정말 그랬냐"는 추궁으로 읽힌다. 그때는 인정하고 감사로 닫는다.
- **상대가 쓴 단어를 그대로 되돌려 쓴다.** ("banking app" → "your bank app")
- **이모지는 문장당 최대 하나**, 그것도 공감 문장에만. 🙌 🫡 😅 정도. 없어도 된다.
- **감사 인사로 시작하지 않는다.** "Thanks for sharing!"은 자동응답처럼 읽힌다.
  바로 상대 얘기로 들어간다.
- 새 사실은 **하나만**. 두 개면 하나를 버린다. 연도·이름 하나면 충분하다 —
  설명은 붙이지 않는다. 궁금하면 상대가 되묻는다. 그게 스레드다.

## 출력 형식

답글은 **영어로 쓰고, 바로 밑에 한글 해석을 붙인다.** 해석은 사용자가 읽고 확인하는
용도다 — **실제로 다는 댓글은 영어만.** 한글을 댓글에 같이 올리지 않는다.
(첫 댓글 `reply`는 영어 + `· · ·` + 한국어로 함께 올리는 것과 다르다. 헷갈리지 말 것.)

```
Kaspi's ahead of us there 🙌 Korea only got its ID into KakaoTalk in 2025 — the kiosks live on for the stamped paper. Any paper left in 🇰🇿?
```
> 그 점은 카스피가 저희보다 앞서 있네요 🙌 한국은 2025년에야 신분증이 카카오톡에
> 들어왔고, 무인발급기는 도장 찍힌 종이 때문에 아직 살아 있어요. 카자흐스탄엔 아직
> 종이 쓸 일이 남아 있나요?

해석은 직역하지 않는다. 영어가 친근하게 읽히면 한글도 친근하게 읽혀야 한다 —
그래야 톤이 맞는지 사용자가 판단할 수 있다.

## 영어는 미국식으로 쓴다

독자 다수가 미국인이다. **영국식 단어·철자가 하나 섞이면 그 문장만 번역기처럼 읽힌다.**
글로 배운 영어 티를 내는 건 콩글리시만큼 나쁘다.

| 쓰지 말 것 | 쓸 것 |
|---|---|
| boot (차) | trunk |
| motorway | highway |
| queue | line |
| petrol | gas |
| fortnight | two weeks |
| whilst / amongst | while / among |
| quite (꽤) | pretty |
| lovely / brilliant | great / nice |
| at the weekend | on the weekend |
| maths | math |
| colour, realise, practise, neighbourhood | color, realize, practice, neighborhood |
| I shall / one does | I'll / you |

- **줄표(—)를 쓰지 않는다.** 지금 영어권에서 em dash는 "AI가 썼다"는 신호로 읽힌다.
  쉼표로 끊거나, 마침표로 문장을 나누거나, 괄호를 쓴다. 한 답글에 하나도 없어야 한다.
- **한 문장에 절을 세 개 이상 쌓지 않는다.** 매끄럽게 이어붙일수록 사람 말이 아니게 된다.
  짧은 문장 두 개가 긴 문장 하나보다 낫다.
- **"It's not X, it's Y" 같은 대구를 반복하지 않는다.** 한 답글에 한 번이면 충분하고,
  여러 답글에 계속 나오면 문체가 기계처럼 굳는다.
- **축약형을 쓴다.** it is → it's, that is → that's, you are → you're. 안 쓰면 딱딱해진다.
- **문어체 접속사 금지.** moreover, furthermore, hence, thus. 대신 and, so, but.
- 감탄은 `That's wild`, `Oh that's interesting`, `Honestly`, `Fair enough`, `Ha` 정도.
  `Indeed`, `Quite so`는 사람 말투가 아니다.
- 숫자·단위도 현지식으로. 거리는 맥락상 필요하면 마일 병기, 돈은 원 그대로 쓰되
  `about $200` 식으로 감을 붙여도 된다.

## 유형별

| 댓글 | 답글 |
|---|---|
| "우리나라는 더 잘한다" | 먼저 맞다고 한다. 지지 않으려 하면 그 댓글창은 국가 대항전이 된다. 그 나라 고유명사 하나를 정확히 알고 있음을 보이고("Kaspi", "MyNumber"), 한국이 왜 그 모양인지를 한 문장으로 준 뒤 되묻는다 |
| 질문 | 답부터. 모르면 "모른다"가 정답이다. 지어내면 팩트체크 규칙 전체가 무너진다 |
| 정정 (우리가 틀림) | 즉시 인정하고 고맙다고 한다. 변명 금지. 카드가 틀렸으면 `content/<date>.json`의 fact_check에 남긴다 |
| 목격담 반박 ("실제로는 안 그렇던데") | 상대 경험을 예외로 깎지 않는다. **카드가 실제보다 매끈했다는 걸 먼저 인정**하고, 우리가 아는 정도(흔하진 않다 / 늘고 있다)를 조심스럽게 덧붙인 뒤 질문 없이 고맙다고 닫는다 |
| 정정 (상대가 틀림) | "Actually..." 로 시작하지 않는다. 출처를 조용히 하나 대고 넘어간다 |
| 경험담·자기 나라 얘기 | 새 사실 없이 짧게 받고 한 번 더 물어도 된다. 이게 스레드를 살린다 |
| 단순 칭찬 | 답글 대신 좋아요. 답글은 반박·질문·정보 추가에만 쓴다 |
| 긴 칭찬 (정성껏 쓴 것) | **그대로 받는다. 토 달지 않는다.** "사실 한국에서도 과하다는 논쟁이 있다" 같은 반전을 붙이면 꼬인 사람처럼 읽힌다. 대신 한 칸 낮춰 받고("안에서 보면 평범한 일이에요"), 다른 나라 사람들을 향한 바람으로 닫는다 |
| 다른 나라를 깎으며 한국을 올림 ("Take that, USA!") | 올라타지 않는다. 칭찬 부분만 받고 `Nobody has to lose for it` 식으로 방향을 튼다. 훈계하지 말고 내 바람으로 말한다 |
| 자기 나라가 더 낫다고 말함 | 좋다고 인정한다. `I'd take that 😊` 한 줄이면 충분하다. 한국 사정을 변호하지 않는다 |
| 규모·거리 비교 | 상대 경험을 깎지 않는다. **우리 쪽을 낮춘다** — "한국은 좁아서 평소엔 네 시간, 명절이 그걸 아홉 시간으로 만든다" 처럼 우리의 진짜 변수를 밝힌다 |
| 링크를 걸어줌 | **실제로 읽고 답한다.** 그 안의 고유명사 하나(yu fai, bengkung)를 문장에 넣으면 읽었다는 증거가 된다. 안 읽고 고맙다고만 하면 티가 난다 |
| 우리 제도를 써본 외국인의 솔직한 후기 | 변호하지 않는다. 경험을 부정하는 셈이 된다. 프레임을 넓히고("집에서 받는 것도 한국식"), 본인이 이미 정한 방향에 쓸모 있는 정보만 하나 얹는다 |
| 긴 개인 경험담 | 정보를 얹지 말고 **그 이야기에서 제일 좋은 대목 하나를 골라 되돌려준다.** 이미 말한 사정을 다시 요약하지 않는다 |
| "AI로 쓴 거 아니냐" 류 조롱 | 부인도 변명도 하지 않는다. 무시가 기본. 답한다면 한 줄로 인정하고 계정의 값어치로 화제를 돌린다 — `Fair enough 🙂 The English I'm still working on. The Korea part I know.` |
| 남의 나라 정치·부패 한탄 | 정치는 받지 않는다. 그 안의 **알맹이(불평등, 교육 기회 등)만** 한국 사례로 받아주고 나머지는 지나간다 |
| 정치 유도, 인신공격, 혐오 | 답하지 않는다. 답글은 노출을 키운다. 숨김이 맞다 |
| 상표가 섞인 경험담 | 링크·할인코드·계정 태그가 없으면 그냥 자기가 쓰는 물건 이름을 말한 것이다. **제품 부분은 빼고** 나머지에만 답한다. 브랜드명을 답글에 되풀이하지 않는다 — 우리 계정이 무료 매대가 된다 |
| 제품 링크·이미지 URL | 광고다. **답글 없이 삭제·숨김.** 같은 스레드에 답글을 달면 그 링크까지 같이 올라온다. 특히 산모·수험생처럼 취약한 독자가 보는 글에서는 효과가 확립되지 않은 건강 상품을 방치하지 않는다. 재범하면 차단 |
| 무거운 개인사 (입양인, 사별, 차별 경험) | **피하지 않는다.** 주제 위에 서 있는 이야기라 침묵이 곧 "당신은 여기 속하지 않는다"가 되고, 좋아요만 눌러도 같다. 대신 아래 규칙을 따른다 |

## 무거운 개인사 댓글

글의 주제 위에서 자기 상처를 말한 사람에게는 **짧게, 한 번, 이모지 없이, 질문 없이** 답한다.
길이 규칙(150자)은 여기서만 넘겨도 되지만, 말이 길수록 위태로워진다는 걸 기억한다.

- **페이지가 줄 수 있는 것은 하나뿐이다: "당신도 여기 사람이다."** 위로도 진단도 조언도
  페이지의 몫이 아니다. 상담자 역할을 떠맡지 않는다.
- 한국이 공식적으로 인정한 사실이 있으면 그것만 조용히 댄다. 그 사람에게는 "내 얘기가
  인정받았다"는 뜻이 된다. (예: 2025년 3월 진실화해위원회가 해외입양 과정의 '고아 호적'
  등 기록 조작을 확인하고 국가의 공식 사과를 권고 — 신청인 56명 1차 진실규명)
- **묻지 않은 실무 조언을 먼저 꺼내지 않는다.** 가족 찾기, 호적 정정, 기관 안내 —
  본인이 물어봤을 때만.
- 되묻지 않는다. 질문은 더 말하라는 요구가 된다.
- 상대가 더 길게 답해오면 짧게 한 번 더 받고 놓는다. 끝까지 함께해야 할 의무는 없다.
- **그 사연을 카드뉴스 소재로 쓰지 않는다.** 본인 동의 없이는.
- 공개 답글이 부담스러운 내용이면 DM을 함께 쓴다.

## 하지 말 것

- 한국 미화, 자기 비하, 방어. (카드뉴스 지침과 같다)
- 확인 안 된 숫자. 카드에 못 쓸 수치는 답글에도 못 쓴다
- 카드나 캡션에 이미 쓴 문장 반복. 답글은 새 정보 아니면 값이 없다
- 같은 스레드에서 같은 말 두 번
- 링크. 인스타에서 죽은 텍스트고 스팸으로 읽힌다
- 상대 목격담을 "그건 드문 경우"로 정리하기. 사실이어도 무례하게 읽힌다 —
  "카드가 깔끔하게 보이게 만들었다"로 우리 쪽을 낮추면 같은 뜻이 예의 있게 전달된다
- 칭찬에 반전 붙이기. 정확해도 꼬인 사람으로 읽힌다
- 남의 나라 정치·정부·제도 평가. 그 나라 사람이 먼저 욕해도 같이 욕하지 않는다
- 같은 인사말 복붙. 한 글에서 여러 명이 비슷한 제보를 하면 문장을 바꾼다 —
  "이 댓글창에서만 벌써 네 번째 이름이네요" 처럼 스레드를 엮으면 다음 제보를 부른다
- 묻지 않은 조언. 본인이 이미 그 방향을 정한 경우에만 쓸모 있는 정보를 하나 얹는다

## 기록

**답글 기록은 사용자가 직접 남긴다. 파일을 만들지 않는다.** 답글은 대화에 영어 + 한글
해석으로 내놓고 끝낸다. 리포에 커밋할 것은 답글 자체가 아니라 **다음에도 쓰일 규칙과,
한 번 확인한 사실**이다 — 아래.

## 확인해둔 사실 (재조사 금지, 그대로 재활용)

답글에 자주 필요한데 매번 다시 찾게 되는 것들. 새로 확인한 게 생기면 여기에 한 줄 추가한다.
**여기 없는 숫자는 답글에 쓰지 않는다.**

- **모바일 신분증**: 2025년 7월부터 네이버·카카오톡·토스·삼성월렛에서 모바일 주민등록증
  발급. 실물 주민등록증과 법적 효력 동일. (정책브리핑 148940749, 정부24 CappBizCD=17410000052)
- **여권**: 본인 직접 신청 원칙(여권법 제9조 2항). 온라인 재발급은 2020-12-18부터 가능하지만
  **수령은 방문이 원칙**. (외교부 passport.go.kr, 정부24)
- **노약자석**: 정식 명칭은 교통약자석. 처벌 조항 없음, 1980년 1호선에서 시작.
  '요즘 젊은 사람이 앉는 게 늘었다'는 **추세 통계가 없다** — 인상으로만 쓴다.
- **코로나 거리두기와 목욕장업**: 2단계 '2+α'에서 사우나·한증막 운영 중단 — 목욕탕은 열고
  찜질 시설만 닫았다. 발한실 2m 거리두기, 완화기 23시 영업 제한. (중대본 거리두기 안내,
  정책브리핑 148876465)
- **정부24**: 2023년 4월 가입자 2000만 명, 인구 3명 중 1명. 연도를 반드시 붙여 쓴다.
- **카자흐스탄**(비교 대상으로 자주 나옴): Digital Documents가 eGov mobile 외에 Kaspi.kz·
  Halyk Homebank 은행 앱에서도 열린다. 신분증·운전면허 등 18종. (egov.kz)
- **수능 항공 통제**: 영어듣기 35분간 전국 이착륙 전면 통제, 비행 중 항공기는 고도 3km 이상
  대기. **비상·긴급 항공기는 예외.** 조정 편수는 해마다 다름(2025학년도 156편). (국토교통부)
- **학원 교습시간**: 서울은 조례로 밤 10시까지. 24시간 스터디카페가 그 자리를 메운다.
- **학연**: 혈연·지연과 함께 한국을 움직이는 세 가지로 불린다. 학벌 얘기에 쓰기 좋다.
- **우골탑**: 1950~60년대, 소 팔아 등록금을 댄 농가 위에 세워진 대학. 그 세대 얘기에 쓴다.
- **수능 백일기도**: 100일 전부터 절·교회에서 매일 기도. 시험 당일만이 아니다.
- **산후조리**: 조리원 표준 2주, 삼칠일(21일)이 원형. 배우자는 대개 상주 가능하고 그 외
  방문객은 면회실까지. **비용은 자부담** — 좋은 곳은 출산 비용보다 비싸다. 집에서 받는
  산모신생아 건강관리 바우처(주민센터)도 있다.
- **산후조리 실태조사 2024**(보건복지부): 조리원 이용률 **85.5%**, 평균 체류 **12.6일**,
  평균 비용 **286.5만원**(재가 125.5만원). 선호도 70.9%, 산모가 가장 원하는 정책은
  산후조리 경비지원(60.1%). 조리원이 보편적이라는 근거로 이 숫자를 쓴다.
- **산후조리 지원금은 지자체별**: 경기도 산후조리비 50만원은 2026-09-30 종료, 서울은
  2026년 상향(첫째 100·둘째 120·셋째 이상 150만원, 신청 180일). 국가 산모신생아
  건강관리 지원사업은 계속. "전국 공통"으로 말하지 않는다.
- **산후조리 비슷한 제도**: 태국 yu fai(อยู่ไฟ, 불 곁에 1주~1개월), 말레이 berpantang
  (44일, bengkung 복대·tungku 찜질). 둘 다 "몸의 열을 되찾는다"는 같은 논리.
- **전세 비슷한 제도**(댓글에서 모인 것): 볼리비아 anticrético, 케랄라 otti, 타밀나두
  bogiyam, 뭄바이 heavy deposit, 필리핀 sangla-tira. 카드에 'only in Korea'를 쓰지 않는 이유.
- **주택임대차 순위**: 인도+전입신고로 대항력, 확정일자로 우선변제권. **근저당보다 앞서야**
  낙찰자가 미배당 보증금을 인수한다. 뒤지면 경매로 소멸. 이 갈림길을 빼면 틀린 답이 된다.
- **추석**: 통행료 3일 면제, 서울~부산 평소 4시간이 피크엔 9시간+. 스팸 선물세트가 대표 선물.

  인허가 데이터로 직접 셀 것.

업계 공통 권장형이라는 것은 여러 소셜 운영 가이드에서 반복되는 내용이다:

대응), Sculpt(브랜드 목소리의 일관성). 트롤에 답하지 않는 것도 공통이다.
