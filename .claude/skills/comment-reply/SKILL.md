# 댓글 답글

읽는 사람은 스크롤 중이다. **짧고, 먼저 공감하고, 질문으로 끝낸다.** 그게 전부다.
설명하고 싶어지면 그건 다음 카드뉴스 소재이지 답글이 아니다.

## 기본형

```
[공감 — 상대 말이 맞다고 인정] + [새 사실 한 개] + [짧은 질문]
```

- **1~2문장 + 질문. 영어 150자 안팎, 200자를 넘기지 않는다.** 문단 나누지 않는다.
  길게 쓰고 싶어질 때 버릴 것부터 정한다: 수식어 → 부연 → 두 번째 사실 순.
- **보통은 물음표로 끝낸다** — 마침표로 끝내면 대화가 닫히고, 질문은 상대가 자기 나라
  얘기를 하게 만든다. **단, 상대가 우리를 정정했거나 자기 목격담을 말한 경우는 예외다.**
  거기서 되물으면 "정말 그랬냐"는 추궁으로 읽힌다. 그때는 인정하고 감사로 닫는다.
- **상대가 쓴 단어를 그대로 되돌려 쓴다.** ("banking app" → "your bank app")
- **이모지는 문장당 최대 하나**, 그것도 공감 문장에만. 🙌 🫡 😅 정도. 없어도 된다.
- **감사 인사로 시작하지 않는다.** "Thanks for sharing!"은 자동응답처럼 읽힌다.
  바로 상대 얘기로 들어간다.
- 새 사실은 **하나만**. 두 개면 하나를 버린다. 연도·이름 하나면 충분하다 —
  설명은 붙이지 않는다. 궁금하면 상대가 되묻는다. 그게 스레드다.

## 출력 형식

답글은 **영어로 쓰고, 바로 밑에 한글 해석을 붙인다.** 해석은 사용자가 읽고 확인하는
용도다 — **실제로 다는 댓글은 영어만.** 한글을 댓글에 같이 올리지 않는다.
(첫 댓글 `reply`는 영어 + `· · ·` + 한국어로 함께 올리는 것과 다르다. 헷갈리지 말 것.)

```
Kaspi's ahead of us there 🙌 Korea only got its ID into KakaoTalk in 2025 — the kiosks live on for the stamped paper. Any paper left in 🇰🇿?
```
> 그 점은 카스피가 저희보다 앞서 있네요 🙌 한국은 2025년에야 신분증이 카카오톡에
> 들어왔고, 무인발급기는 도장 찍힌 종이 때문에 아직 살아 있어요. 카자흐스탄엔 아직
> 종이 쓸 일이 남아 있나요?

해석은 직역하지 않는다. 영어가 친근하게 읽히면 한글도 친근하게 읽혀야 한다 —
그래야 톤이 맞는지 사용자가 판단할 수 있다.

## 유형별

| 댓글 | 답글 |
|---|---|
| "우리나라는 더 잘한다" | 먼저 맞다고 한다. 지지 않으려 하면 그 댓글창은 국가 대항전이 된다. 그 나라 고유명사 하나를 정확히 알고 있음을 보이고("Kaspi", "MyNumber"), 한국이 왜 그 모양인지를 한 문장으로 준 뒤 되묻는다 |
| 질문 | 답부터. 모르면 "모른다"가 정답이다. 지어내면 팩트체크 규칙 전체가 무너진다 |
| 정정 (우리가 틀림) | 즉시 인정하고 고맙다고 한다. 변명 금지. 카드가 틀렸으면 `content/<date>.json`의 fact_check에 남긴다 |
| 목격담 반박 ("실제로는 안 그렇던데") | 상대 경험을 예외로 깎지 않는다. **카드가 실제보다 매끈했다는 걸 먼저 인정**하고, 우리가 아는 정도(흔하진 않다 / 늘고 있다)를 조심스럽게 덧붙인 뒤 질문 없이 고맙다고 닫는다 |
| 정정 (상대가 틀림) | "Actually..." 로 시작하지 않는다. 출처를 조용히 하나 대고 넘어간다 |
| 경험담·자기 나라 얘기 | 새 사실 없이 짧게 받고 한 번 더 물어도 된다. 이게 스레드를 살린다 |
| 단순 칭찬 | 답글 대신 좋아요. 답글은 반박·질문·정보 추가에만 쓴다 |
| 정치 유도, 인신공격, 혐오 | 답하지 않는다. 답글은 노출을 키운다. 숨김이 맞다 |
| 무거운 개인사 (입양인, 사별, 차별 경험) | **피하지 않는다.** 주제 위에 서 있는 이야기라 침묵이 곧 "당신은 여기 속하지 않는다"가 되고, 좋아요만 눌러도 같다. 대신 아래 규칙을 따른다 |

## 무거운 개인사 댓글

글의 주제 위에서 자기 상처를 말한 사람에게는 **짧게, 한 번, 이모지 없이, 질문 없이** 답한다.
길이 규칙(150자)은 여기서만 넘겨도 되지만, 말이 길수록 위태로워진다는 걸 기억한다.

- **페이지가 줄 수 있는 것은 하나뿐이다: "당신도 여기 사람이다."** 위로도 진단도 조언도
  페이지의 몫이 아니다. 상담자 역할을 떠맡지 않는다.
- 한국이 공식적으로 인정한 사실이 있으면 그것만 조용히 댄다. 그 사람에게는 "내 얘기가
  인정받았다"는 뜻이 된다. (예: 2025년 3월 진실화해위원회가 해외입양 과정의 '고아 호적'
  등 기록 조작을 확인하고 국가의 공식 사과를 권고 — 신청인 56명 1차 진실규명)
- **묻지 않은 실무 조언을 먼저 꺼내지 않는다.** 가족 찾기, 호적 정정, 기관 안내 —
  본인이 물어봤을 때만.
- 되묻지 않는다. 질문은 더 말하라는 요구가 된다.
- 상대가 더 길게 답해오면 짧게 한 번 더 받고 놓는다. 끝까지 함께해야 할 의무는 없다.
- **그 사연을 카드뉴스 소재로 쓰지 않는다.** 본인 동의 없이는.
- 공개 답글이 부담스러운 내용이면 DM을 함께 쓴다.

## 하지 말 것

- 한국 미화, 자기 비하, 방어. (카드뉴스 지침과 같다)
- 확인 안 된 숫자. 카드에 못 쓸 수치는 답글에도 못 쓴다
- 카드나 캡션에 이미 쓴 문장 반복. 답글은 새 정보 아니면 값이 없다
- 같은 스레드에서 같은 말 두 번
- 링크. 인스타에서 죽은 텍스트고 스팸으로 읽힌다
- 상대 목격담을 "그건 드문 경우"로 정리하기. 사실이어도 무례하게 읽힌다 —
  "카드가 깔끔하게 보이게 만들었다"로 우리 쪽을 낮추면 같은 뜻이 예의 있게 전달된다

## 예시

> "In 🇰🇿 u can do get it all on a banking and a egov app on ur smartphone."

```
Kaspi's ahead of us there 🙌 Korea only got its ID into KakaoTalk in 2025 — the kiosks live on for the stamped paper. Any paper left in 🇰🇿?
```

공감 → 새 사실(2025년 모바일 신분증) → 질문. 137자. 한글 해석은 위 「출력 형식」 참고.

버린 것: "genuinely", "carrying your documents", "and Toss", "because someone still
wants". 사실은 그대로 남고 길이만 절반이 됐다.

## 기록

**답글 기록은 사용자가 직접 남긴다. 파일을 만들지 않는다.** 답글은 대화에 영어 + 한글
해석으로 내놓고 끝낸다. 리포에 커밋할 것은 답글 자체가 아니라 **다음에도 쓰일 규칙과,
한 번 확인한 사실**이다 — 아래.

## 확인해둔 사실 (재조사 금지, 그대로 재활용)

답글에 자주 필요한데 매번 다시 찾게 되는 것들. 새로 확인한 게 생기면 여기에 한 줄 추가한다.
**여기 없는 숫자는 답글에 쓰지 않는다.**

- **모바일 신분증**: 2025년 7월부터 네이버·카카오톡·토스·삼성월렛에서 모바일 주민등록증
  발급. 실물 주민등록증과 법적 효력 동일. (정책브리핑 148940749, 정부24 CappBizCD=17410000052)
- **여권**: 본인 직접 신청 원칙(여권법 제9조 2항). 온라인 재발급은 2020-12-18부터 가능하지만
  **수령은 방문이 원칙**. (외교부 passport.go.kr, 정부24)
- **노약자석**: 정식 명칭은 교통약자석. 처벌 조항 없음, 1980년 1호선에서 시작.
  '요즘 젊은 사람이 앉는 게 늘었다'는 **추세 통계가 없다** — 인상으로만 쓴다.
- **코로나 거리두기와 목욕장업**: 2단계 '2+α'에서 사우나·한증막 운영 중단 — 목욕탕은 열고
  찜질 시설만 닫았다. 발한실 2m 거리두기, 완화기 23시 영업 제한. (중대본 거리두기 안내,
  정책브리핑 148876465)
- **정부24**: 2023년 4월 가입자 2000만 명, 인구 3명 중 1명. 연도를 반드시 붙여 쓴다.
- **카자흐스탄**(비교 대상으로 자주 나옴): Digital Documents가 eGov mobile 외에 Kaspi.kz·
  Halyk Homebank 은행 앱에서도 열린다. 신분증·운전면허 등 18종. (egov.kz)

확인 못 한 것도 적어둔다 — 다음에 또 유혹당하지 않게:

- 코로나 3년간 서울 목욕장업 242곳 폐업: 단일 출처. 쓰려면 서울 열린데이터광장 목욕장업
  인허가 데이터로 직접 셀 것.
- 동대문 스파렉스·용산 드래곤힐스파·이태원랜드 폐업/휴업: 상호 특정 주장인데 단일 출처.
- 무인민원발급기가 외국인등록증을 받는지: 확인 안 됨. 기계·지자체마다 다르다.

## 근거

빠른 답글이 첫 몇 시간의 확산을 좌우하고(인스타는 활발한 댓글창을 신호로 읽는다),
짧은 답글이 긴 답글보다 반응이 좋다는 것, "공감 → 정보 한 개 → 질문" 구조가
업계 공통 권장형이라는 것은 여러 소셜 운영 가이드에서 반복되는 내용이다:
Buffer(답글이 참여도를 21% 올린다는 자체 데이터), NapoleonCat, Brandwatch(댓글 유형별
대응), Sculpt(브랜드 목소리의 일관성). 트롤에 답하지 않는 것도 공통이다.
