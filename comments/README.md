# 댓글 대응

우리가 발행 직후 다는 첫 댓글은 `content/<date>.json`의 `reply`다. 이 폴더는
그다음, 즉 **남이 단 댓글에 답하는 것**을 기록한다. 답한 뒤 `comments/<발행일>.md`에
원문 그대로와 우리 답, 근거를 남긴다. 같은 반박이 다음 편에도 또 오기 때문이다.

## 원칙

1. **반박이 맞으면 맞다고 먼저 말한다.** 이 계정의 무기는 맥락이지 애국심이 아니다.
   "한국이 더 낫다"로 받으면 그 댓글창은 국가 대항전이 되고, 아래 달릴 댓글도 그렇게 된다.
2. **그 나라 사정을 하나 정확히 안다는 걸 보여준다.** 이름을 안다는 신호("Kaspi",
   "Halyk")가 일반론 열 줄보다 낫다. 틀리게 아는 척은 하지 않는다 — 확인한 것만 쓴다.
3. **카드에 없던 사실을 하나 더 준다.** 답글도 콘텐츠다. 요약 반복은 아무것도 안 남긴다.
4. **왜 한국은 그 모양인지로 되돌린다.** 댓글이 지적한 차이를 계정의 주제
   (한국적 맥락)로 되돌리는 게 답글의 일이다.
5. **질문으로 끝낸다.** 예/아니오로 닫히지 않는 형태로. 첫 댓글 규칙과 같다.
6. **길이:** 영어 3~4문장. 첫 댓글(400자)보다 짧게. 스레드에서는 500자에서 잘린다.
7. **하지 말 것:** 방어, 사과, 이모지 도배, 정정 없는 수치 추가. 답글에 새 숫자를
   쓰면 카드와 같은 기준으로 검증하고 여기에 근거를 남긴다.

## 답하지 않는 댓글

- 정치 편들기를 유도하는 것 (남북, 한일, 특정 정당). 좋아요만 누르거나 넘긴다.
- 인신공격·혐오. 답글은 노출을 키운다. 숨김이 맞다.
- 단순 칭찬. 좋아요로 충분하다. 답글은 반박·질문·정보 추가에만 쓴다.
